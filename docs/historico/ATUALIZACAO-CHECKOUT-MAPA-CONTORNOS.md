# Atualização — checkout limpo e áreas apenas por contorno

## Cliente
- O mapa não é mais exibido automaticamente no checkout.
- As áreas/taxas de entrega nunca são desenhadas no mapa do cliente.
- A pesquisa de endereço completo aparece primeiro.
- CEP preenche rua e bairro automaticamente.
- Localização atual preenche endereço por geocodificação reversa.
- Rua, bairro, número e CEP ficam visíveis para conferência; cidade/UF permanecem internas.
- O mapa só abre quando o cliente escolhe “Ver / ajustar localização no mapa”.
- O cálculo de taxa continua automático, sem exigir que o cliente confirme no mapa.

## Admin
- Áreas personalizadas são desenhadas somente com linhas de contorno.
- Não há preenchimento colorido, portanto uma região não cobre visualmente a cor da outra.
- As cores diferentes permanecem nos contornos.
- O encaixe automático de bordas continua ativo para evitar lacunas entre áreas.
