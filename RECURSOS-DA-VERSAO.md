# Mapa de recursos inspirado nas telas de referência

| Área vista nas referências | Implementação nesta versão |
|---|---|
| Pedidos PDV | Módulo `Pedidos PDV`, carrinho rápido, estoque compartilhado |
| Vendas / histórico / relatórios | `Vendas e caixa`, resumo, histórico diário, CSV |
| Caixas | Abertura/fechamento e alerta global de caixa fechado |
| Lançamentos financeiros | Receitas/despesas manuais |
| Cardápio / página de produtos | Produtos, categorias, disponibilidade, fotos e site conectado |
| Página de boas-vindas | Capa, logo, cores e textos editáveis pelo admin |
| Cozinha | KDS com relógio, prioridade por horário e cores |
| Inventário | Estoque, mínimo, disponível/esgotado e alertas |
| Clientes | Segmentos, ciclo, pontos, CPF protegido, novo cliente, CSV |
| Cupons | Cupons percentual/valor fixo |
| Fidelidade | Pontos por compra e meta configurável |
| Envio WhatsApp | Segmentos + mensagens prontas / links de conversa |
| Google para o negócio | Links do Perfil da Empresa e avaliação |
| Avaliações | Nota interna 1–5 + emojis + CTA para Google |
| QR e links | QR de boas-vindas e cardápio |
| Equipe e funções | Cadastro de colaboradores e papéis-base |
| Métodos de pagamento | PIX, dinheiro e cartão configuráveis |
| Impressoras e tickets | Manual, PDF e agente de impressão automática |
| Totem | Rota `/totem` configurável |
| Nota fiscal | Gancho para provedor fiscal; credenciais externas obrigatórias |
| Chatbot | Assistente rápido de dúvidas + WhatsApp |
| Ferramentas de rastreamento | Google Analytics e Meta Pixel configuráveis |
