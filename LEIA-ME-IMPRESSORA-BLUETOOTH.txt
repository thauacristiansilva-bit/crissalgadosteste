SABORFLOW - CORRECAO DA FILA E IMPRESSORA BLUETOOTH

1. Extraia este ZIP DENTRO da pasta original do projeto e substitua os arquivos.
2. No VS Code, abra Terminal > Novo Terminal e execute:

   git add .
   git commit -m "Corrige fila de impressao e inclui Bluetooth"
   git push origin main

3. Espere a Railway terminar o deploy e recarregue a pagina do SaborFlow.
4. No computador Windows que vai imprimir, ligue e pareie a impressora
   Bluetooth em Configuracoes > Bluetooth e dispositivos > Impressoras e scanners
   > Adicionar dispositivo. O Windows precisa reconhece-la como impressora.
5. Na area Impressora do SaborFlow, abra novamente o arquivo
   CONECTAR-IMPRESSORA-SABORFLOW.cmd que voce ja baixou. Isso carrega o
   conector atualizado do servidor. Deixe a janela aberta.
6. Clique em Atualizar lista no painel e selecione a impressora. Se ainda
   nao aparecer, confira se ela esta instalada em Impressoras e scanners.

O agente instalado no Windows envia para o SaborFlow a lista de impressoras
instaladas. O navegador nao pode parear fisicamente a impressora a distancia.
O erro 503 foi corrigido no escopo de consulta ao banco; se ainda aparecer,
verifique no Railway os logs do servico e o estado do banco de dados.
Nenhuma migracao adicional de banco e necessaria para este pacote.
