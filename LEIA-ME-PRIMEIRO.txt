SABORFLOW — PRÉVIA VISUAL ANTES DE PUBLICAR

1. Abra no VS Code a pasta ORIGINAL do projeto, onde está package.json.
2. Extraia este ZIP dentro dessa pasta e aceite substituir os arquivos.
3. No terminal do VS Code, rode um comando por vez:

git add .
git commit -m "Mostra previa visual da loja na IA"
git push origin main

4. Aguarde o deploy no Railway e atualize o admin. Não há migração de banco nesta etapa.

TESTE:
- Admin > Montar loja com IA > escreva "Organize a página inicial da loja e
  sugira um título e cores da logo" > Gerar prévia.
- Acima dos campos, aparece "Como o cliente verá a página". Alterne entre
  Celular e Computador e role dentro da página.
- Logo abaixo, a tabela mostra onde o campo fica no admin, o valor antigo e
  o novo. Edite um título ou cor: a visualização deve mudar imediatamente.
- Nada é publicado até tocar em "Aprovar e publicar as alterações".

Esta visualização reutiliza o componente da landing page pública, mas os links
estão desativados na prévia. Produtos novos sem preço continuam invisíveis até
que você informe o preço e aprove o plano.

Verificações: npm run typecheck, npm run build e regras de enquadramento da rota
verificadas. O teste interativo com sessão autenticada exige conferir no Railway.
