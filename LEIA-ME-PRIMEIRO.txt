SABORFLOW — IA AMPLIADA + AJUSTE DE BEBIDA NO COMBO

1. Abra a pasta ORIGINAL do projeto no VS Code (a que contem package.json).
2. Extraia o ZIP DENTRO dessa pasta e aceite substituir os arquivos.
3. No Terminal do VS Code, execute UM COMANDO POR VEZ:

git add .
git commit -m "Amplia assistente de IA e corrige escolha da bebida"
git push origin main

4. Aguarde o deploy do servico sabor flow no Railway. Atualize a pagina do admin.
   Nesta atualizacao NAO ha migracao de banco.

PARA TESTAR A IA:
No painel > Montar loja com IA, peça por texto ou voz:
"Reorganize a landing page. Melhore o titulo e a descricao, sugira cores da logo
ja cadastrada, destaque o combo existente e sugira tres legendas para Instagram."
Veja a previa. Toque em "Aprovar e publicar as alteracoes" para salvar a loja.
A IA agora trabalha com conteudo da loja, configuracoes de atendimento e horarios,
produtos novos e existentes, grupos/sabores e sugestoes de produtos. A logo deve
estar cadastrada em Configuracoes; se nao for possivel le-la, a previa informa.
Pedidos que nao sao suportados aparecem em "Pedidos que precisam de outro passo".
As legendas sao para copiar: nao sao postadas no Instagram automaticamente.

PARA A BEBIDA NO COMBO:
No grupo de bebidas, marque obrigatorio, minimo 1 e maximo 1. Em "Mais opcoes",
"Quantidade incluida no preco" = 1 se ja faz parte do preco do combo;
= 0 se for cobrada a parte. Ao reduzir maximo, esse campo agora se ajusta sozinho.

Verificacao local: npm run typecheck e npm run build passaram.
A geracao com Gemini e o salvamento no banco precisam ser conferidos no Railway.
